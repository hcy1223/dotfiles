# VS Code Profiles

Put optional `.code-profile` exports in this directory.

These files must be exported manually from VS Code:

```text
Profiles -> Export Profile... -> Local File
```

Import them manually on another machine:

```text
Profiles -> Import Profile... -> Select File...
```

Daily VS Code dotfiles are still managed through:

- `../User/settings.json`
- `../User/keybindings.json`
- `../User/snippets/`
- `../extensions.txt`
